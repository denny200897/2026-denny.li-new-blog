開源、自架的 Linux 伺服器控制面板，所有功能免費。

- 管理 Docker 容器
- 一鍵部署網站（靜態網站、WordPress、Ghost）
- 監控系統資源
- 透過 SSH 執行遠端指令
- 架構：Next.js 前端 + FastAPI 後端
